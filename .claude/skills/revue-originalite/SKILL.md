# Revue d'originalité

Pour chaque écran, noter dans `docs/originality-review.md` : ce qui est repris (un comportement), ce qui diffère (disposition, mouvement, icônes, noms, sons), puis le jugement (« assez différent » ou « à retravailler »).
Références : Playnite plein écran, Steam Big Picture, Xbox, PS5, Switch. **Aucune capture n'est livrée, décalquée ni placée dans le dépôt.**
La charte est dans `docs/design.md` (direction Iris).
